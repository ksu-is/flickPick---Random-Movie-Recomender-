# READ ME!
flickPick is a beginner-friendly Python movie randomizer that helps users decide what to watch by generating random movie recommendations based on their genre or mood. It's perfect for movie lovers who need help picking their next film! 🍿

Created by Jasmyn Williams, based on source codes:
https://github.com/ksu-is/MovieRec and https://github.com/AD-Archer/MoviesNoir-Movie-Generator/blob/main/script.js
